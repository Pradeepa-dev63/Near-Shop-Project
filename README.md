# NearShop

Project split into three folders:

- `frontend` — customer-facing React/Vite application
- `backend` — Node/Express API and server
- `admin` — standalone React/Vite admin dashboard

## Run frontend
cd frontend
npm install
npm run dev

## Run backend
cd backend
npm install
npm start

## Run admin
cd admin
npm install
npm run dev

The frontend and admin both expect the backend API at `http://localhost:5000`.
